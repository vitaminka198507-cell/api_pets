# API Dog & Cat

Небольшой Flask-проект, который показывает случайную картинку собачки или котика.

Используются публичные API:

- Dog CEO API для случайных картинок собак
- CATAAS — Cat as a Service для случайных картинок котиков

## Возможности

- Стартовая веб-страница без автозагрузки картинки
- Кнопка `🐶 Получить собачку`
- Кнопка `🐱 Получить котика`
- Консольное меню для получения ссылки на случайную собачку или котика
- Запуск через Docker Compose

## Запуск локально без Docker

Установите зависимости:

```bash
pip install -r requirements.txt
```

Запустите веб-приложение:

```bash
python3 web_app.py
```

Откройте в браузере:

```text
http://127.0.0.1:5001
```

## Запуск через Docker

Соберите и запустите контейнер:

```bash
docker compose up --build -d
```

Откройте в браузере:

```text
http://127.0.0.1:5001
```

Остановить контейнер:

```bash
docker compose down
```

## Веб-маршруты

- `/` — стартовая страница с двумя кнопками
- `/?pet=dog` — получить случайную собачку
- `/?pet=cat` — получить случайного котика

## Консольный режим

Запустите:

```bash
python3 main.py
```

В меню доступны пункты:

```text
1 - Получить случайную собачку
2 - Получить случайного котика
q - Выход
```

## CI/CD

В проекте настроен автоматический деплой через GitHub Actions.

При push в ветку `main`:
- собирается Docker-образ;
- образ публикуется в GitHub Container Registry;
- новая версия автоматически деплоится на сервер.

Изменения только в `README.md` не запускают workflow и не вызывают автодеплой.

Workflow находится в `.github/workflows/deploy.yml`.

Секреты для подключения к серверу хранятся в GitHub Actions Secrets и не находятся в репозитории.
